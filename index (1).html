Networking Fundamentals

What is a Computer Network?

A computer network is a group of devices connected together so they can share resources and communicate with each other.

Network Types

  • LAN (Local Area Network): Small area (home, school, office)
  • WAN (Wide Area Network): Large geographic area (connects cities – the Internet is the biggest WAN)
  • WLAN (Wireless Local Area Network): Wireless version of a LAN (Wi-Fi)

Key Devices

  • Client: Device that requests data (laptop, phone)
  • Server: Powerful computer that provides services/files
  • Router: Connects different networks and routes traffic
  • Switch: Connects devices within the same LAN
  • Access Point: Enables wireless (Wi-Fi) connections

Vocabulary

  • Protocol: Rules for how devices communicate
  • Bandwidth: Amount of data that can be sent per second
  • Router / Switch / Access Point / Client / Server / LAN / WAN

IP Addressing and MAC Addresses

IP Address

An IP address is like a street address for devices on a network.

  • IPv4: 192.168.1.1 (32-bit, most common)
  • IPv6: 2001:db8::1 (128-bit, much larger address space)

MAC Address

A MAC address is a unique hardware address assigned to every network card. It looks like: 00-1A-2B-3C-4D-5E.

The first 3 octets (OUI) identify the manufacturer (e.g., Apple, Dell, Cisco).

Examples

  • Private IP: 192.168.1.50 (used inside your home/school)
  • Public IP: The address your ISP gives you (visible on the internet)

Other Terms: Subnet Mask, Default Gateway, DNS Server

Networking Tools and Labs

Lab 1: ipconfig and ping

I used Command Prompt to run ipconfig /all to view my IP address, MAC address, subnet mask, and default gateway. I then used ping 8.8.8.8 and ping www.google.com to test connectivity.

Reflection: I learned that ping uses ICMP and is a key troubleshooting tool.

Lab 2: Wireshark Packet Capture

I captured live network traffic while browsing. I observed DNS queries, TCP handshakes, and HTTP/HTTPS packets.

Reflection: This showed me how data actually travels across networks in packets and the difference between TCP and UDP.

Networking Careers and Certifications

Career 1: Network Administrator

Manages company networks, routers, switches, and user access.

Career 2: Cybersecurity Analyst

Monitors networks for threats and protects systems from attacks.

Career 3: Cloud Network Engineer

Designs and manages networks in cloud platforms (AWS, Azure).

Recommended Certifications

  • CompTIA Network+
  • Cisco CCNA
  • CompTIA Security+
